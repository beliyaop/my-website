# 每日日记

一个一页式的极简日记网页：**每天写一句话就算记录成功，数据只存在你自己的浏览器里。**

没有账号、没有服务器、没有广告。打开就能写，写完关掉，明天再来。

---

## 本地运行（怎么把它跑起来）

### 第一步：打开终端，进入项目目录

```
cd D:\工作空间\my-website
```

### 第二步：启动一个本地小服务器

```
python -m http.server 8000 --bind 127.0.0.1
```

这条命令的每个部分在做什么：

| 部分 | 作用 |
|---|---|
| `python` | 用 Python 自带的模块起服务，不用装任何东西 |
| `-m http.server` | 启动一个最简单的「只读文件服务器」 |
| `8000` | 占用 8000 端口（被占了就换一个，比如 8080） |
| `--bind 127.0.0.1` | 只允许本机访问，不对局域网开放 |

**成功标志**：终端打印出下面这行之后**停住不退出**（这是正常的，它在等你访问）：

```
Serving HTTP on 127.0.0.1 port 8000 (http://127.0.0.1:8000/) ...
```

### 第三步：浏览器打开

```
http://localhost:8000
```

### 用完怎么关

回到那个终端窗口，按 `Ctrl + C`。

### 为什么不直接双击 index.html

双击打开时地址栏是 `file:///D:/...`，不是网页真正的运行方式。项目里生成条目编号用的 `crypto.randomUUID()` **只在 `http://localhost` 或 `https://` 下可用**，走 `file://` 会退回到备用方案。用本地服务器打开，才和将来上线后的环境一致。

## 文件分工

| 文件 | 负责什么 |
|---|---|
| `index.html` | 页面结构：列表视图 + 详情视图，用 `hidden` 属性切换，不需要路由 |
| `style.css` | 版式：手机单列不横向滚动；桌面正文居中、最宽 720px |
| `app.js` | 全部逻辑：读写本地存储、渲染列表、保存、收藏、视图切换 |
| `data-flow.svg` | 数据流图（技术设计文档引用） |

没有 `package.json`、没有 `node_modules`、不需要构建——**改完文件刷新浏览器即生效**。

## 数据存在哪

所有日记都写在浏览器自己的 `localStorage` 里，键名 `diary.entries`。一条日记长这样：

```json
{
  "id": "a1b2c3d4",
  "date": "2026-10-02",
  "text": "今天学会了写验收标准",
  "favorite": false,
  "createdAt": "2026-10-02T23:10:00"
}
```

- **不会上传到任何服务器**——页面上的「日记只保存在此浏览器，不会上传」是事实，不是承诺。
- 代价也要说清：**换设备、清浏览器缓存、换浏览器，日记就看不到了**。导出备份功能排在后续第一批。

## 已实现 / 还没做

**已实现（MVP）**

- 历史列表，按日期从新到旧

- 导出备份、删除与编辑单条、按月浏览
